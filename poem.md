# Lumiere dans le terminal

Le soir descend sur les fenetres,
un reflet dort contre l'ecran;
les lignes cherchent leurs promesses,
comme des etoiles dans le vent.

Un mot s'allume, puis deux encore,
la nuit respire entre les doigts;
dans le silence du decor,
une idee trouve enfin sa voie.

Je confie au papier de verre
des phrases simples, sans detour;
elles traversent la poussiere
pour rapporter un peu de jour.

Et quand la page se repose,
calme, ouverte, au bord du temps,
le monde tient dans peu de choses:
un titre, un souffle, un battement.
